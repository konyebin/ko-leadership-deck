First 180 days — before the cohort starts

Day 0–180 · prep runway, no ASEs in seat yet

0–30 Listen

  • Meet program owners, prior managers, sales leaders who'll host shadows
  • Audit CSAP/ASE materials—what's current, what's missing
  • Learn cohort timeline: hiring, start date, how many seats
  • Shadow active SE teams—refresh what good looks like on calls

31–60 Build

  • Draft week-by-week onboarding for day 1 of the program
  • Coaching rubric tied to CSAP milestones
  • Lock shadow roster with sellers before anyone arrives
  • Pilot AMA format with TSS peers as stand-in audience

61–90 Lock in

  • Dry-run onboarding; fix materials from feedback
  • Dashboard spec—what I'll track from cohort day 1
  • Mentor/sponsee matches lined up before start
  • Leadership sign-off on KPIs and success metrics

91–180 Ready at go-live

  • Final material pass; handoff docs if I'm out
  • Pre-start sync with stakeholders on expectations
  • Runbook for the cohort's first 30 days once they're here
  • Day-180 checkpoint: ready or not for cohort start
